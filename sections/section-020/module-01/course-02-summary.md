# Summary

Artifacts connect task-produced data to later consumers through a supported storage contract. The producing path, repository location and consuming reference must agree; scalar parameters solve a different input problem.

Credentials, archive behavior and retention determine accessibility and lifecycle. A successful process can still omit a required output, while retries and reused locations can create collisions unless identity and ownership are designed deliberately.
