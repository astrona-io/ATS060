# Generating and Consuming Artifacts

This section covers artifacts: files that tasks produce and consume, the artifact repository that stores them, the sources an input can use, and the cleanup of objects and logs.

## Modules

- Generating, Storing And Consuming Workflow Artifacts: artifacts compared with parameters, outputs, inputs and the repository.
- Artifact Sources, Archive Options And Cleanup: raw, git, http and s3 inputs, packing, keys, garbage collection and log archiving.

Each module has a landing page, deep-dive parts, a guided practice session in a private playground and a summary. Graded labs follow the part they practise. A capstone lab closes the section, and a knowledge check follows it.

## Learning Outcomes

- Distinguish artifacts from scalar parameters.
- Trace output files through repository storage and input references.
- Explain repository credentials and where the repository is configured.
- Choose input sources and archive options for a stated need.
- Configure artifact garbage collection and log archiving and evaluate missing outputs and retention.
