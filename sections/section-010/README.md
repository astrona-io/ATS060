# Understand Argo Workflow Fundamentals

This section covers the Argo Workflows resources, the templates that define work, and the components that run a Workflow. It also covers how to submit a Workflow, read its results and control what stays after the run.

## Modules

- Workflow Resources, Templates And Execution Ownership: the custom resources, templates, controller, pods and executor.
- Running And Inspecting Workflows: submission, arguments, status, logs, ttlStrategy and podGC.

Each module has a landing page, deep-dive parts, a guided practice session in a private playground and a summary. Graded labs follow the part they practise. A capstone lab closes the section, and a knowledge check follows it.

## Learning Outcomes

- Distinguish a Workflow execution from its reusable templates.
- Explain controller, pod and executor responsibilities.
- Interpret entrypoint, arguments and node status.
- Submit a Workflow, override its arguments and read its output parameters.
- Choose retention fields for a stated need and evaluate identity and cleanup independently of execution success.
