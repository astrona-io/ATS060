# Understand Argo Workflow Fundamentals

This section covers understand Argo Workflow Fundamentals. It develops workflow Resources, Templates And Execution Ownership through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Distinguish a Workflow execution from its reusable templates.
- Explain controller, Pod and executor responsibilities.
- Interpret entrypoint, arguments and node status.
- Evaluate identity and cleanup independently of execution success.
