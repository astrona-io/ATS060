# Understand the Argo Workflow Spec

This section covers how to read a Workflow spec and how its controls shape a run.

## Modules

- Reading The Workflow Spec: entrypoint, templates, arguments, retry, deadline, parallelism and cleanup.
- Resources, Identity, Placement And Status: requests, limits, ServiceAccount, placement, volumes and failure evidence.

Each module has a landing page, deep-dive parts, a guided practice session in a private playground and a summary. Graded labs follow the part they practise. A capstone lab closes the section, and a knowledge check follows it.

## Learning Outcomes

- Read a spec from the entrypoint outward.
- Choose the right lifecycle control for a stated problem.
- Relate resource, identity and placement fields to pod start.
- Separate declared spec from observed status.
