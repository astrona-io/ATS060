# Understand the Argo Workflow Spec

This section covers understand the Argo Workflow Spec. It develops reading Workflow Spec Fields As Execution Decisions through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain entrypoint, templates, arguments and task inputs.
- Relate resource, identity and placement settings to execution.
- Distinguish retry, timeout and cleanup controls.
- Interpret status and external side effects separately from desired spec.
